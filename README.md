# 任务计划 · 桌面悬浮版

一个极简的**桌面悬浮任务计划**工具。
支持写任务、设置 DDL、每日重复任务。窗口可置顶悬浮在桌面任意位置。

## 主要特性

- 悬浮在桌面（无边框 + 置顶）
- 顶部可拖动移动窗口
- 置顶切换（图钉按钮）
- 添加任务 + DDL时间（精确到分钟） + 节假日自动标明 + 每天重复
- 每日重复任务点击「完成今日」自动顺延 1 天
- 筛选、搜索、编辑、删除
- 数据保存为本地 JSON 文件（关掉重开还在，更可靠）

## 运行方式（推荐）

### 1. 第一次运行

1. 确保你已安装 Python（没有就去 https://www.python.org 下载安装）
2. 在本文件夹打开终端（PowerShell 或 CMD），执行：

```bash
pip install -r requirements.txt
python app.py
```

3. 窗口会以悬浮窗形式出现（默认置顶、可拖动）

### 2. 后续使用

直接双击 `app.py` 运行（或右键用 Python 打开）

## 窗口操作

- **拖动**：鼠标按住顶部灰色标题栏拖动窗口
- **置顶**：点击图钉图标切换是否始终在最前
- **最小化**：点击 − 按钮
- **关闭**：点击 × 按钮（本地 JSON 文件保存，数据不会丢失）

## 操作提示

- 添加任务时可设置精确到分钟的 DDL
- 节假日日期会自动标明 🎉（如端午、国庆）
- 重复任务 → 紫色「完成今日」（自动 +1 天，保留时间）
- 普通任务 → 绿色「完成」
- 按键盘 `/` 快速搜索
- `Esc` 取消编辑

## 数据说明

- 所有任务保存在**本地 JSON 文件**（比 localStorage 更可靠）
- Windows 路径：`%APPDATA%\任务计划\tasks.json`（通常是 `C:\Users\你的用户名\AppData\Roaming\任务计划\tasks.json`）
- 关掉重开、电脑重启后任务仍然保留
- 删除 `app.py` 或整个文件夹**不会丢失**你的任务数据
- 如需备份，可直接复制上面的 `tasks.json` 文件

## 打包成独立 .exe（可选）

以后想做成无需 Python 的单个程序：

```bash
pip install pyinstaller
pyinstaller --onefile --windowed --name "任务计划" app.py
```

生成的可执行文件在 `dist/` 文件夹。
