# 任务计划 · 桌面悬浮版

一个极简的**桌面悬浮任务计划**工具。
支持写任务、设置 DDL、每日重复任务。窗口可置顶悬浮在桌面任意位置。

## 主要特性

- 悬浮在桌面（无边框 + 置顶）
- 顶部可拖动移动窗口
- 置顶切换（图钉按钮）
- 添加任务 + DDL + 每天重复
- 每日重复任务点击「完成今日」自动顺延 1 天
- 筛选、搜索、编辑、删除
- 数据本地存储（关掉重开还在）

## 运行方式（推荐）

### 1. 第一次运行

1. 确保你已安装 Python（没有就去 https://www.python.org 下载安装）
2. 在本文件夹打开终端（PowerShell 或 CMD），执行：

```bash
pip install -r requirements.txt
python app.py
```

3. 窗口会以悬浮窗形式出现（默认置顶、可拖动）

### 2. 后续使用

直接双击 `app.py` 运行（或右键用 Python 打开）

## 窗口操作

- **拖动**：鼠标按住顶部灰色标题栏拖动窗口
- **置顶**：点击图钉图标切换是否始终在最前
- **最小化**：点击 − 按钮
- **关闭**：点击 × 按钮（数据不会丢失）

## 操作提示

- 添加任务时可勾选「每天重复」
- 重复任务 → 紫色「完成今日」
- 普通任务 → 绿色「完成」
- 按键盘 `/` 快速搜索
- `Esc` 取消编辑

## 数据说明

- 所有任务保存在本地（浏览器 localStorage，由 pywebview 使用）
- 删除 `app.py` 或文件夹不影响已保存数据（除非清浏览器数据）

## 打包成独立 .exe（可选）

以后想做成无需 Python 的单个程序：

```bash
pip install pyinstaller
pyinstaller --onefile --windowed --name "任务计划" app.py
```

生成的可执行文件在 `dist/` 文件夹。
